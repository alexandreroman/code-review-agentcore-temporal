# Project objective

Agentic Review with Temporal (repository `temporal-agentic-review`) is a
conference demo, licensed Apache-2.0: AI agents review the pull requests of a
dedicated demo repository, orchestrated by Temporal and executed as Serverless
Workers on Amazon Bedrock AgentCore. The talk lasts 15 minutes and shows only
two screens, GitHub and Temporal UI. It demonstrates four moments:
scale-from-zero, parallel reviewer agents, durability after `/kill` of the
AgentCore sessions, and human-in-the-loop with `/fix`.

**Why:** the audience must see, live and without incident, why Temporal and
AgentCore matter for agentic workloads.

**How to apply:** favour reliability and readability on stage over features;
anything that does not serve one of the four moments is out of scope.
