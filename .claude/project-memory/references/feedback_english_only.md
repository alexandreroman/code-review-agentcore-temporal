# English only for generated text

All text generated for the project is written in English: code, comments,
docstrings, log and error messages, tests, commit messages, documentation
(README, SETUP, DEMO, specs, plans), configuration comments, skills and project
memory. Conversations with the user may happen in another language; the
artifacts do not.

**Why:** the project is a public conference demo shared with an international
audience and team.

**How to apply:** write every file and commit message in English, including
design documents and plans; translate any non-English text found in the
repository.
